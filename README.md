# ⏱️ Digital Stopwatch Application

A modern and responsive Stopwatch web application built using HTML5, CSS3, and Vanilla JavaScript.

## ✨ Features
- Start, Pause, and Reset functionalities.
- Clean and interactive Dark Mode UI.
- Precise time tracking using JavaScript timers.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
